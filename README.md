# 谁是卧底 · 5人同车版

5 个人在车上各自用手机加入同一个房间，一起玩的「谁是卧底」网页游戏。

## 玩法

1. 一个人点 **创建房间**，把 4 位房间号（或分享链接）发给朋友
2. 其他 4 个人点 **加入房间**，输入房间号
3. 5 个人都到齐后，房主点 **开始游戏**
4. 系统随机给 4 人发相同的词（平民词），给 1 人发相近但不同的词（卧底词）
5. 每人轮流用一句话描述自己的词（不能直接说出来）
6. 描述完一轮后所有人投票选出怀疑的卧底
7. 票数最高的人被淘汰：
   - 是卧底 → 平民胜利
   - 不是卧底 → 卧底胜利，游戏结束
8. 房主可点 **再来一局** 或 **返回大厅**

## 技术

- 纯前端单页应用（`index.html`）
- 通过 [Yjs](https://github.com/yjs/yjs) + [y-webrtc](https://github.com/yjs/y-webrtc) 实现点对点同步，无需自建后端
- 使用公共信令服务器（wss://signaling.yjs.dev 等）
- 状态用 CRDT 自动合并，断线重连不会丢数据

## 本地运行

直接用浏览器打开 `index.html` 即可，或：

```bash
npx serve .
```

## 部署

任意静态托管都行：

- **Vercel**: `vercel deploy`
- **Netlify**: 拖拽 `index.html` 到 https://app.netlify.com/drop
- **GitHub Pages**: 推送到 main，开启 Pages
